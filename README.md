# Список задач

Тестовое задание для The Digital: простой To-Do List на HTML, CSS и JavaScript без фреймворков и сборки.

**Сайт:** https://arina-todo-list.netlify.app

## Что умеет

По заданию:
- добавить задачу (кнопкой или Enter);
- отметить выполненной и снять отметку;
- удалить;
- после обновления страницы всё на месте (localStorage).

Сверх задания, потому что без этого пользоваться неудобно:
- переименовать задачу: карандаш или двойной клик, Enter сохраняет, Esc отменяет;
- вернуть случайно удалённую задачу (кнопка «Вернуть» в течение 6 секунд);
- фильтры «Все / Активные / Готово» со счётчиками, фильтр сохраняется в адресе (`#/active`), работает кнопка «Назад»;
- «Убрать выполненные» одной кнопкой;
- счётчик со склонением: 1 задача, 3 задачи, 5 задач;
- если список открыт в двух вкладках, изменения в одной сразу видны в другой;
- тёмная тема по настройке системы;
- на телефоне кнопки видны всегда, на компьютере появляются при наведении;
- всё работает с клавиатуры, у кнопок есть подписи для скринридеров.

Мелочи, которые проверены отдельно:
- пустую задачу или задачу из одних пробелов добавить нельзя;
- длинный текст переносится и не ломает вёрстку, длина ограничена 200 символами;
- текст задачи выводится через `textContent`, так что `<script>` в названии останется просто текстом;
- если в localStorage лежит мусор или браузер запрещает хранилище (приватный режим), приложение не падает, а показывает предупреждение.

## Как запустить

Сайт статический, но скрипты подключены как ES-модули, а они не открываются через `file://`. Нужен любой локальный сервер:

```bash
npm start
```

Откроется на http://localhost:3000. Ставить зависимости не нужно.

Тесты (Node.js 20+):

```bash
npm test
```

## Как устроено

```
index.html          разметка и шаблон строки задачи
css/style.css       стили, светлая и тёмная тема
js/todos.js         логика списка: чистые функции без DOM
js/storage.js       чтение и запись в localStorage с проверкой данных
js/app.js           работа со страницей: события, отрисовка, фокус
tests/              тесты на node:test для todos.js и storage.js
netlify.toml        настройки Netlify: тесты перед выкладкой, заголовки безопасности
```

Логику держу отдельно от страницы: функции в `todos.js` принимают массив и возвращают новый, ничего не меняя. Их легко проверить тестами, а `app.js` только вызывает их и перерисовывает список. Для списка дел этого хватает, фреймворк тут был бы лишним.

Тесты гоняются в GitHub Actions на каждый пуш и на Netlify перед каждой выкладкой.

## Какие ИИ-инструменты использовала

- **Claude Code** (модель Claude Opus): код, тесты, README и выкладка через GitHub и Netlify.
- Проверка: 15 автотестов плюс ручной прогон во встроенном браузере Claude Code на ширине компьютера и телефона, в светлой и тёмной теме. Прошлись по добавлению, отметке, удалению с отменой, переименованию, обновлению страницы, двум вкладкам и попытке вставить HTML в название задачи.
