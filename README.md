# Список задач

Тестовое задание для The Digital: To-Do List на HTML, CSS и JavaScript без фреймворков и сборки.

**Сайт:** https://arina-todo-list.netlify.app

## Что умеет

По заданию:
- добавить задачу (кнопкой или Enter);
- отметить выполненной и снять отметку;
- удалить;
- после обновления страницы всё на месте (localStorage).

Сверх задания. Смотрела, как устроены Todoist, Things 3, TickTick, Microsoft To Do и Sunsama, и взяла то, без чего ими неудобно пользоваться:
- **быстрый ввод**: пишете «Позвонить в банк завтра !1 #дела», и задача сама получает срок, приоритет и метку. Под полем видно, что распознано; если слово распозналось зря, его можно снять крестиком. Понимает русский и английский: «сегодня», «послезавтра», «в пятницу», «через 3 дня», «25.11», «25 ноября», «tomorrow», «next friday», «nov 25», «in 2 weeks»;
- **повторы**: «Планёрка каждый понедельник», «Зарядка каждый день», «Отчёт по будням», «every friday». Отметили задачу, и следующий раз появился сам. Пропущенные дни не копятся: просроченная ежедневная задача встаёт на завтра, а не тянет за собой хвост;
- **шаги и заметка** внутри задачи: «1/3» под названием раскрывает список, шаги отмечаются прямо в нём, новый добавляется Enter, готовый список можно вставить целиком (каждая строка станет шагом). Когда все шаги готовы, список предлагает отметить задачу, но не отмечает сам;
- **перенос срока в два нажатия**: клик по сроку или по «⋯» открывает меню «на сегодня / на завтра / на следующую неделю / без срока / выбрать дату», рядом видно, какая это будет дата. С клавиатуры: T (на сегодня) и M (на завтра);
- **просроченное без чувства вины**: в «Сегодня» оно собрано отдельной группой с кнопкой «Перенести всё на сегодня» и возможностью вернуть как было;
- **разделы** «Все», «Сегодня», «Планы», «Готово» со счётчиками и **прогресс дня** «Сегодня сделано 2 из 5»;
- **приоритеты** 1–3: цвет кружка и флажок с подписью, чтобы приоритет читался не только цветом; **метки**: клик по метке показывает все задачи с ней;
- **поиск** по названию, меткам, шагам и заметкам (клавиша `/`), найденное подсвечивается; **сортировка**: свой порядок, по сроку, по приоритету;
- **перетаскивание** за ручку мышью и пальцем, с клавиатуры Alt + ↑/↓;
- **редактор задачи**: название, срок, повтор, приоритет, метки, шаги, заметка. Двойной клик по названию или карандаш;
- **отмена**: удалённую, отмеченную или перенесённую задачу можно вернуть кнопкой в сообщении или Ctrl+Z;
- **первый визит**: вместо пустого экрана три задачи-примера, которые сами показывают шаги, повтор и быстрый ввод. Убираются одной кнопкой;
- **справка «Быстрый ввод и клавиши»** (кнопка «?» или клавиша `?`): все примеры быстрого ввода и горячие клавиши N, /, 1–4, J/K, X, E, T, M, Del;
- **работает без интернета**: после первого визита страница открывается и офлайн, её можно установить на телефон как приложение;
- **русский и английский** интерфейс: язык берётся из браузера, переключается кнопками RU / EN, меняются все подписи, даты, склонения («1 задача, 2 задачи, 5 задач») и `lang` у страницы;
- **светлая тема** основная, тёмная включается кнопкой, выбор запоминается;
- **скачать задачи в JSON и загрузить обратно**; если список открыт в двух вкладках, изменения в одной сразу видны в другой.

Задачи из первой и второй версий сайта при первом открытии переносятся в новый формат, ничего не теряется.

Чего сознательно нет: серий дней подряд («стриков»), таймера Pomodoro и напоминаний. Серии давят чувством вины, когда прерываются, а таймер и напоминания для списка в браузере лишние: они раздувают интерфейс сильнее, чем помогают.

Мелочи, которые проверены отдельно:
- пустую задачу или задачу из одних пробелов добавить нельзя;
- «Купить 1.5 литра молока» не превращается в задачу на 1 мая, «Завтрак с Олей» не получает срок «завтра», «Подарок на каждый день рождения» не становится ежедневной задачей;
- длинный текст переносится и не ломает вёрстку;
- текст задачи выводится через `textContent`, так что `<script>` в названии останется просто текстом;
- если в localStorage лежит мусор или браузер запрещает хранилище, приложение не падает, а показывает предупреждение;
- из загружаемого файла берутся только правильные задачи, чужой файл ничего не ломает;
- всё работает с клавиатуры, у кнопок есть подписи для скринридеров, контраст текста не ниже 4.5:1, на телефоне от 320 px нет горизонтальной прокрутки.

## Как запустить

Сайт статический, но скрипты подключены как ES-модули, а они не открываются через `file://`. Нужен любой локальный сервер:

```bash
npm start
```

Откроется на http://localhost:3000. Ставить зависимости не нужно.

Тесты (Node.js 20+):

```bash
npm test
```

## Как устроено

```
index.html            разметка, иконки и шаблоны строки задачи, редактора и меню
css/style.css         стили, светлая и тёмная тема
js/boot.js            ставит тему и язык до отрисовки, чтобы страница не мигала
js/app.js             работа со страницей: события, отрисовка, фокус, клавиши, меню, перетаскивание
js/todos.js           логика списка: разделы, шаги, повторы, перенос, поиск, сортировка, перестановка
js/repeat.js          следующий срок повторяющейся задачи
js/parse.js           разбор быстрого ввода
js/dates.js           даты в виде ГГГГ-ММ-ДД без сдвига часовых поясов
js/i18n.js            тексты на двух языках, склонения, форматы дат
js/storage.js         localStorage с проверкой данных, перенос из v1 и v2, экспорт и импорт
js/samples.js         задачи-примеры для первого визита
sw.js                 работа без интернета: сначала сеть, без сети сохранённая копия
manifest.webmanifest  установка на телефон
tools/make-icons.mjs  рисует PNG-иконки без зависимостей
tests/                тесты на node:test для всего, что не трогает страницу
netlify.toml          настройки Netlify: тесты перед выкладкой, заголовки безопасности
```

Логику держу отдельно от страницы: функции принимают данные и возвращают новые, ничего не меняя. Их легко проверить тестами, а `app.js` только вызывает их и перерисовывает список. Фреймворк для такого объёма был бы лишним.

Тесты гоняются в GitHub Actions на каждый пуш и на Netlify перед каждой выкладкой. Сайт отдаётся с Content-Security-Policy `default-src 'self'`: никаких внешних скриптов, шрифтов и встроенных стилей.

## Какие ИИ-инструменты использовала

- **Claude Code** (модель Claude Opus): код, тесты, README, выкладка через GitHub и Netlify.
- В третьей версии я сначала собрала для Claude Code базу знаний из открытых источников с цитатами и ссылками: законы UX (lawsofux.com), статьи Nielsen Norman Group, модель поведения Фогга, теория самодетерминации, список тёмных паттернов deceptive.design, Apple HIG, Material 3, WCAG 2.2, Refactoring UI, Butterick, справочные центры Todoist, Things, TickTick, Microsoft To Do, Sunsama. На ней работают отдельные агенты:
  - «психолог» разобрал, где пользователю тяжело (куча просроченного, перенос срока в 5 действий, пустой первый экран), и предложил функции с оценкой пользы и стоимости. Часть идей он сам отклонил: серии дней, таймер, окно «спланируй день»;
  - «дизайнер» отвечает за визуальную часть (с v2: цвета с посчитанным контрастом, сетка, состояния элементов);
  - «судья» ставит оценки по 12 критериям (красота, понятность, польза, скорость, доступность, телефон, надёжность, безопасность и другие) и пропускает сайт, только если каждый критерий не ниже 8 из 10, а средний не ниже 9. Если меньше, возвращает на доработку со списком. Вместе с ним «критик» ищет ошибки.
  - Как это сработало: вторая версия получила у судьи в среднем 7.1 из 10. Третья прошла 4 круга «оценка → доработка»: 7.5, 8.0, 8.25, 8.67. В последнем круге каждый из 12 критериев 8 или 9, серьёзных и средних замечаний нет. До порога 9.0 в среднем не хватило мелочей, их список у судьи. По ходу критик нашёл и я исправила потерю набранного текста при «Вернуть», двойные копии повторяющихся задач и сбои при работе в двух вкладках. Отметка задачи в списке из 200 штук на медленном телефоне ускорилась с ~900 до ~100 мс.
- Проверка: автотесты плюс прогоны в браузере (безголовый Chrome через DevTools Protocol) на двух языках, в обеих темах, на ширине от 320 px и только с клавиатуры.

## English

A to-do list in plain HTML, CSS and JavaScript (ES modules, no build, no dependencies). Natural-language quick add in English and Russian (“Call the bank tomorrow !1 #errands”, “Stand-up every monday”), recurring tasks, steps and notes inside a task, two-click rescheduling, “move all overdue to today”, views All / Today / Upcoming / Done, priorities, tags, search, sorting, drag-and-drop with a keyboard alternative, shortcuts, undo, JSON export and import, first-visit examples, offline support (service worker), light and dark themes, RU/EN interface. Data stays in localStorage. Run `npm start` to serve it and `npm test` for the tests. Built with Claude Code, with research-backed design, UX-psychology and judge agents.
