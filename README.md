# Список задач

Тестовое задание для The Digital: To-Do List на HTML, CSS и JavaScript без фреймворков и сборки.

**Сайт:** https://arina-todo-list.netlify.app

## Что умеет

По заданию:
- добавить задачу (кнопкой или Enter);
- отметить выполненной и снять отметку;
- удалить;
- после обновления страницы всё на месте (localStorage).

Сверх задания. Смотрела, как устроены Todoist, Things 3, TickTick и Microsoft To Do, и взяла то, без чего ими неудобно пользоваться:
- **быстрый ввод**: пишете «Позвонить в банк завтра !1 #дела», и задача сама получает срок, приоритет и метку. Под полем видно, что распознано; если слово распозналось зря, его можно снять крестиком. Понимает русский и английский: «сегодня», «послезавтра», «в пятницу», «через 3 дня», «25.11», «25 ноября», «tomorrow», «next friday», «nov 25», «in 2 weeks»;
- **разделы** «Все», «Сегодня», «Планы», «Готово» со счётчиками. В «Сегодня» просроченное отдельной группой сверху, в «Планах» задачи сгруппированы по дням;
- **прогресс дня**: «Сегодня сделано 2 из 5» с полоской;
- **приоритеты** 1–3: цвет кружка и флажок с подписью, чтобы приоритет читался не только цветом;
- **метки**: клик по метке показывает все задачи с ней;
- **поиск** по названию и меткам (клавиша `/`), найденное подсвечивается;
- **сортировка**: свой порядок, по сроку, по приоритету;
- **перетаскивание** за ручку мышью и пальцем, с клавиатуры Alt + ↑/↓;
- **редактор задачи**: название, срок (календарь), приоритет, метки. Двойной клик по названию или кнопка с карандашом;
- **отмена**: удалённую или отмеченную задачу можно вернуть кнопкой в сообщении или Ctrl+Z;
- **горячие клавиши**: N, /, 1–4, J/K, X, E, Del, ?, Esc. Список открывается по `?`;
- **русский и английский** интерфейс: язык берётся из браузера, переключается кнопками RU / EN, меняются все подписи, даты, склонения («1 задача, 2 задачи, 5 задач») и `lang` у страницы;
- **светлая тема** основная, тёмную можно включить кнопкой, выбор запоминается;
- **скачать задачи в JSON и загрузить обратно** (кнопка с файлом рядом с переключателем языка);
- если список открыт в двух вкладках, изменения в одной сразу видны в другой;
- на телефоне разделы листаются лентой, кнопки у задач видны всегда, на компьютере появляются при наведении.

Задачи из первой версии сайта (ключ `todo-list:v1`) при первом открытии переносятся в новый формат, ничего не теряется.

Мелочи, которые проверены отдельно:
- пустую задачу или задачу из одних пробелов добавить нельзя;
- «Купить 1.5 литра молока» не превращается в задачу на 1 мая, «Завтрак с Олей» не получает срок «завтра»;
- длинный текст переносится и не ломает вёрстку;
- текст задачи выводится через `textContent`, так что `<script>` в названии останется просто текстом;
- если в localStorage лежит мусор или браузер запрещает хранилище, приложение не падает, а показывает предупреждение;
- из загружаемого файла берутся только правильные задачи, чужой файл ничего не ломает;
- всё работает с клавиатуры, у кнопок есть подписи для скринридеров, контраст текста не ниже 4.5:1.

## Как запустить

Сайт статический, но скрипты подключены как ES-модули, а они не открываются через `file://`. Нужен любой локальный сервер:

```bash
npm start
```

Откроется на http://localhost:3000. Ставить зависимости не нужно.

Тесты (Node.js 20+):

```bash
npm test
```

## Как устроено

```
index.html          разметка, иконки и шаблоны строки задачи и редактора
css/style.css       стили, светлая и тёмная тема
js/boot.js          ставит тему и язык до отрисовки, чтобы страница не мигала
js/app.js           работа со страницей: события, отрисовка, фокус, клавиши, перетаскивание
js/todos.js         логика списка: разделы, поиск, сортировка, перестановка
js/parse.js         разбор быстрого ввода
js/dates.js         даты в виде ГГГГ-ММ-ДД без сдвига часовых поясов
js/i18n.js          тексты на двух языках, склонения, форматы дат
js/storage.js       localStorage с проверкой данных, перенос из v1, экспорт и импорт
tests/              тесты на node:test для всего, что не трогает страницу
netlify.toml        настройки Netlify: тесты перед выкладкой, заголовки безопасности
```

Логику держу отдельно от страницы: функции принимают данные и возвращают новые, ничего не меняя. Их легко проверить тестами, а `app.js` только вызывает их и перерисовывает список. Фреймворк для такого объёма был бы лишним.

Тесты гоняются в GitHub Actions на каждый пуш и на Netlify перед каждой выкладкой. Сайт отдаётся с Content-Security-Policy `default-src 'self'`: никаких внешних скриптов, шрифтов и встроенных стилей.

## Какие ИИ-инструменты использовала

- **Claude Code** (модель Claude Opus): код, тесты, README, выкладка через GitHub и Netlify.
- Во второй версии в Claude Code работали два отдельных агента: «дизайнер» предложил визуальное направление (цвета с посчитанным контрастом, шрифты, сетку, состояния элементов), а «критик» проверял готовый сайт на компьютере и телефоне, на двух языках, с клавиатуры, на доступность и странные данные. Найденное исправлено, критик проверял повторно.
- Проверка: автотесты плюс прогон во встроенном браузере Claude Code.

## English

A to-do list in plain HTML, CSS and JavaScript (ES modules, no build, no dependencies). Natural-language quick add in English and Russian (“Call the bank tomorrow !1 #errands”), views All / Today / Upcoming / Done, due dates, priorities, tags, search, sorting, drag-and-drop with a keyboard alternative, shortcuts, undo, JSON export and import, light and dark themes, RU/EN interface. Data stays in localStorage. Run `npm start` to serve it and `npm test` for the tests. Built with Claude Code.
